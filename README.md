# ぞろぞろうーちー 🐮

はぐれうーちーを集めて、電脳に呑まれたスプカウを救う、ぞろぞろ隊列アクション。
ブラウザだけで遊べる、HTML 1ファイルのゲームです。

## あらすじ

うーちーたちがのんびり暮らす世界。スプカウと王冠のうーちーは、昔からのともだちでした。
でも、いつからかスプカウは輪に入れなくなり、さみしさの果てに電脳に呑み込まれてしまいます。

そのとき、世界のあちこちに「はぐれうーちー」が現れました。
彼らはスプカウを浄化するためのプログラム。浄化は消すことではなく、電脳だけを溶かして、もとのスプカウに戻すこと。

はぐれうーちーを集めて、スプカウを助けにいこう。

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面をドラッグ | 矢印キー |
| あつまれ | 右下ボタンを長押し | スペース |
| 一時停止 | のこり時間をタップ | のこり時間をクリック |

- はぐれうーちーに近づくと、なかまになって一列についてくる
- スコアは「ゴールしたなかまの数 × のこり秒 × 難易度」
- 「あつまれ」で固まると、おもいスイッチに乗れる。8匹以上なら電脳スプカウをはじき返せる（そのかわり足が遅くなる）
- 主人公は落ちないけど、なかまは穴や橋から落ちる

## モード

- **ストーリー**：全10ステージ。集めたはぐれうーちーの累計（浄化パワー）で、エンディングが3種類に分岐
- **サクッとモード**：自動生成のステージをどんどん進む。スプカウは出ない。5面ごとに道が長く、仕掛けが多くなる。進んだ面は保存され、次はつづきから
- **じゆうモード**：うーちーを好きなだけ降らせて遊ぶ。スプカウ召喚、わっか、ジャンプ、撮影モードつき

## 公開のしかた（GitHub Pages）

1. このリポジトリを GitHub に push
2. Settings → Pages → Branch を `main` / `(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

ローカルでは `index.html` をブラウザで開くだけで動きます（初回のみ Three.js を CDN から読み込むため、ネット接続が必要）。

## 技術メモ

- Three.js r128（cdnjs から読み込み）
- 3Dモデル・テクスチャは `index.html` に base64 で埋め込み済み
- BGM・効果音は WebAudio で生成
- ベスト記録は `localStorage` に保存
